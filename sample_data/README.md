# Bundled Demo Data

The application includes a sample senior data analyst role brief, eleven concise anonymized sample resumes, and a pre-computed ranking report. The dashboard's **Explore demo results** action reads the pre-computed report directly, so the presentation path works without an LLM credential or document uploads.

| File | Purpose |
| --- | --- |
| `sample_job_description.txt` | Plain-text Senior Data Analyst role brief used to define the intended skills and experience profile. |
| `sample_resumes.json` | Eleven anonymized resume text fixtures for demo and parser testing. |
| `demo_screening_results.json` | Export-ready ranking report aligned with the supplied role brief and candidate fixtures. |

The sample candidates are invented for testing. They do not represent real job seekers, employees, credentials, or endorsements.
